N8N IMPLEMENTATION GUIDE

Ask every eligible customer for an honest review.

Review automation should make feedback easier. It should not route only happy customers to a public platform while hiding the same option from everyone else.

A neutral request can offer both:
  • an honest public review link
  • a private support route when something needs attention

Those choices should not be mutually exclusive.

Workflow outline

  1. Receive a completed-job event.
  2. Validate the customer and job identifiers.
  3. Check whether contact is permitted.
  4. Wait for the approved period.
  5. Send the same neutral invitation to eligible customers.
  6. Log delivery and surface failures to staff.

Configuration points

Set the review URL, sender identity, delay, contact rules, provider credentials, and staff support destination before activation. Review current destination-platform rules and local laws as part of every deployment.
